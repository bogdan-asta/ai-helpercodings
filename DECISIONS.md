# Принятые решения

- Если переменные Supabase не заданы, приложение использует профиль и задания в localStorage, чтобы демонстрационный сценарий был доступен без внешних сервисов.
- Для серверных операций при настроенном Supabase обязательно нужен service-role ключ; он никогда не отправляется браузеру.
- В локальном режиме демо-профиль не требует внешнего аккаунта; переключение на Supabase происходит автоматически при заполнении его публичных переменных окружения.
